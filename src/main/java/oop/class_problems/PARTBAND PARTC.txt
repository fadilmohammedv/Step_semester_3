PART C — Concept Questions

Question 1
Searching an unsorted 1D array requires linear search with a time complexity of O(n), as every element may need to be checked sequentially. In contrast, a sorted array allows binary search with a time complexity of O(log n). The fundamental reason for this difference is that sorting provides structural order, enabling the algorithm to eliminate half of the remaining search space with each comparison.

Question 2
Big-O notation describes the asymptotic behavior and rate of growth of an algorithm as the input size (n) approaches infinity, rather than counting exact operations. Constant multipliers (like the factor of 2 in 2n) affect execution speed by a constant ratio but do not change the linear growth rate. Therefore, constants are dropped to focus purely on the functional order of growth.

Question 3
In linear data structures (like arrays and linked lists), elements are arranged in a single sequential sequence where each node has at most one predecessor and one successor, allowing traversal in a straightforward linear pass (e.g., left to right). In non-linear data structures (like trees and graphs), elements have hierarchical or complex many-to-many relationships, requiring branching traversal strategies such as Depth-First Search (DFS) or Breadth-First Search (BFS) to visit all nodes.
