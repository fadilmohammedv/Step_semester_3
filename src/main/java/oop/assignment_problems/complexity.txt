Problem 1 - Class Topper Finder
time: O(m * n)
extra space: O(1)

Problem 2 - Merging Two Token Queues
two pointers: time O(m + n), space O(m + n) for the result
join + sort: time O((m + n) log(m + n)), so two pointers is faster

Problem 3 - Most Popular Canteen Order
rescanning for every item: time O(n^2), space O(1)
hash map: time O(n), space O(u) where u = number of distinct items

Problem 4 - Hot Weather Alert Windows
recalculating every block: time O(n * k)
sliding window: time O(n), space O(1)

Problem 5 - Ticket Price Slot Finder
linear scan: time O(n), space O(1)
binary search: time O(log n), space O(1)
